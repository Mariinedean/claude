# Free GeoGuesser Clone

A free, open-source alternative to GeoGuesser that lets you play without paying!

## Features

- Random location generation from around the world
- Google Maps Street View integration
- Points system based on guess accuracy
- Simple and clean interface
- Completely free to use

## How to Play

1. You'll be shown a random Street View location
2. Explore the area using Street View controls
3. Click on the map where you think you are
4. Get points based on how close your guess is!

## Scoring

- 0-10 km away: 5000 points
- 10-50 km away: 4000 points
- 50-100 km away: 3000 points
- 100-500 km away: 2000 points
- 500-1000 km away: 1000 points
- 1000+ km away: 500 points

## Setup

1. Get a free Google Maps API key from [Google Cloud Console](https://console.cloud.google.com/)
   - Enable "Maps JavaScript API" and "Street View Static API"
2. Open `index.html` and replace `YOUR_API_KEY_HERE` with your actual API key
3. Open `index.html` in a web browser
4. Start playing!

## Local Development

Simply open `index.html` in your browser. No build process required!

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Maps JavaScript API
